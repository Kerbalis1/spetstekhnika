# SPETSTEKHNIKA — ELEMENT DIGITAL

Демонстрационный сайт продажи спецтехники на Next.js 15, TypeScript и Tailwind CSS 4. Каталог содержит 26 позиций из предоставленного прайса. Включены пользовательская фотография трёхосного трала и адаптированный логотип с прозрачным фоном. Калькулятор и текстовая заявка используют цены продажи; стоимость SHACMAN F3000 уточнена до 6 500 000 ₽.

## Публикация на GitHub Pages

Репозиторий: `Kerbalis1/spetstekhnika`.
Планируемый адрес: https://kerbalis1.github.io/spetstekhnika/

1. В настройках публичного репозитория откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
3. После загрузки файлов публикация запускается при каждом push в `main`. Проверки и статус доступны на вкладке **Actions**.

Workflow `.github/workflows/pages.yml` устанавливает зависимости, запускает lint, проверку TypeScript и сборку, затем публикует статический экспорт `out/`. Пути ресурсов и canonical настроены для `/spetstekhnika/`. GitHub Pages нужно включить в настройках репозитория; стандартный `GITHUB_TOKEN` не может включить Pages автоматически.

## Локальная проверка

```sh
npm ci
npm run lint
npm run typecheck
NEXT_PUBLIC_BASE_PATH=/spetstekhnika NEXT_PUBLIC_SITE_URL=https://kerbalis1.github.io/spetstekhnika/ npm run build
```

Фотография трала и логотип включены в сборку. Остальные реальные фотографии загружаются с внешних источников и зависят от их доступности. Скачиваемая заявка — демонстрация: данные не отправляются на сервер. Реальные контакты и приём заявок не подключены. Демо не индексируется.
